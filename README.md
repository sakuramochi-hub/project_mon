矢印キーで移動。
スペースキーでジャンプ。
Eキーで憑依。
多くの敵は踏みつけで倒せる。
プレイヤーのHPは5。
被弾時、憑依解除時に1秒間の無敵時間がある。
味方、スライムは大ジャンプ。
味方、ウィスプは石ブロックを通過可能。石ブロック内では憑依解除不可。石ブロック内では自在に飛行できる。敵の投げる石を通過できる。
味方、魔導士は前方にいる敵や、オブジェクトを跳ね返す。ジャンプは不可。
味方、赤い鳥は火の玉を放ちながら飛行可能。スペースキーを押し続けると向きを変えずに移動可能。
敵、スライムは地面をまっすぐ移動する。
敵、コウモリは浮遊しながらまっすぐ移動する。
敵、ウサギはプレイヤーのジャンプに合わせてジャンプする。
敵、アーチャーはプレイヤーを発見次第石を投げる。ウィスプで無効化可能。
敵、ウィッチは移動しながらプレイヤーを見つけ次第火の玉を発射する。
ボスがいる場合はボスを倒すとクリア。不在時はゴールにたどり着くとクリア。
ボス、機械要塞は火の玉攻撃のみ有効。HP50。
ボス、アーマーはスライムの踏みつけのみ有効。攻撃成功後3秒間無敵状態になる。HP5。

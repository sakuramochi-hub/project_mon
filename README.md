矢印キーで移動。
スペースキーでジャンプ。
Eキーで憑依。
多くの敵は踏みつけで倒せる。
プレイヤーのHPは5。
被弾時、憑依解除時に1秒間の無敵時間がある。
スライムは大ジャンプ。一部の強い敵を倒せる。
ウィスプは石ブロックを通過可能。石ブロック内では憑依解除不可。石ブロック内では自在に飛行できる。
赤い鳥は火の玉を放ちながら飛行可能。スペースキーを押し続けると向きを変えずに移動可能。スライムの踏みつけで倒せる。
ボスがいる場合はボスを倒すとクリア。不在時はゴールにたどり着くとクリア。
ボス、機械要塞は火の玉攻撃のみ有効。HP50。
ボス、アーマーはスライムの踏みつけのみ有効。攻撃成功後3秒間無敵状態になる。HP5。
